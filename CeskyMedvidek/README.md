# Český medvídek – Android prototyp

První funkční zdrojová verze dětské aplikace pro učení češtiny.

## Obsah
- modrý medvídek / dětské rozhraní (prototyp)
- 20 českých slov
- česká výslovnost přes Android TextToSpeech (cs-CZ)
- režim učení slov
- hra „Najdi správný obrázek“
- hvězdičky a jednoduchá odměna

## Sestavení
Otevřete kořenovou složku `CeskyMedvidek` v aktuálním Android Studiu, nechte dokončit Gradle Sync a spusťte `Build > Build APK(s)`.

Pozn.: Emoji v prototypu zastupují finální vlastní ilustrace. Pro produkční dětskou aplikaci je vhodné nahradit je jednotnou sadou obrázků a nahraným českým hlasem.
